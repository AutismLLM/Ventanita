Front of house

What the customer experiences

One number, always on
No app to download, no bot menu to navigate, no "reply 1 for pastor, 2 for suadero." Customers text the stand exactly like they'd text a friend, and get answered in Mexican Spanish — chilango slang, not customer-service copy.
Remembers regulars
Every conversation adds to a running note on that customer — what they order, how they like it, whether they always ask for extra salsa. The note travels with them across visits without replaying the whole chat history every time.
Hears, sees, and talks back
A voice note saying "dos de pastor, uno sin cebolla" or a photo of a handwritten office lunch list works the same as typed text — and a reply can be spoken back, useful mid-rush and for regulars who'd rather listen than read.
Pays without leaving the chat
A Mercado Pago link lands in the same thread as the order. Card, transfer, or wallet — whatever the customer already has set up.

Back of house

What's actually running

Handles a rush, not one line at a time
When four tables text at once, Ventanita works through all of them in one pass — oldest unanswered first — instead of freezing on whichever chat happened to be on top of the screen.
Waits for you to finish typing
If a customer is still composing, Ventanita holds its answer — the same courtesy a person would extend — rather than replying to half a thought.
Knows the order's real status
Every ticket moves through a real lifecycle — new → preparing → ready → paid — with cancellations tracked as their own outcome, not lost as a typo in a free-text field.
Tracks how people actually pay
Cash, transfer, card, or Mercado Pago — recorded per order, alongside each customer's preferred method, so the second link is never a guess.
Picks its model, not the other way around
A model running entirely on the operator's own machine when the order matters more than the polish, or a rented cloud model paid per message when it doesn't — the same stand can switch without touching how it talks to customers.

Under the hood

Built to be understood by one person

Every "AI customer engagement platform" charging $500 a month is running the same idea Ventanita is: read a message, decide what it means, write back. The difference is what's between those two lines. Ventanita keeps it small enough that the person running the stand can still open the file and understand every step — no orchestration layer, no message queue, no vendor to call when it breaks at 9pm on a Friday.

RUNTIMEOne process, on the operator's own computer — no cloud account required to keep taking orders.
MEMORYA single SQLite file. Customers, orders, and conversation history — open it with any database viewer, no server involved.
LANGUAGE MODELSwappable behind one seam — a hosted model billed per message, or a local model with no per-message cost at all.
PAYMENTSMercado Pago Checkout — a link per order, confirmation matched back to the customer who placed it.
VOICE & VISIONVoice notes transcribed, photos read, replies optionally spoken back.
OWNERSHIPEvery record — every order, every conversation — lives on hardware the operator owns.
Why it exists

The toll booth was never necessary

A cook can't type and flip tortillas at the same time. That's the whole problem the billion-dollar "conversational commerce" industry charges per message to solve. Ventanita solves it once, on hardware the stand already owns, in a voice that sounds like the stand — not a template Meta pre-approved.
